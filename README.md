# Terbinafine Bilosomes — Scientific References

A text-only, logo-free, lightweight static reference page for the Master's scientific poster by Ahmed Taha A. Sayed, Faculty of Pharmacy, Assiut University.

## Files
- `index.html` — user-approved responsive design; eight DOI-linked citations.
- `references.pdf` — compact printable/downloadable bibliography generated from the same citations.
- `.nojekyll` — optional GitHub Pages compatibility marker.

## GitHub Pages (free, public repository)
1. On GitHub create a new **Public** repository, e.g. `terbinafine-poster-references`. Choose to add a README if asked.
2. Open the repository and use **Add file → Upload files**. Upload `index.html`, `references.pdf`, and `.nojekyll` from this folder. Commit to `main`.
3. Open **Settings → Pages → Build and deployment**. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** and click **Save**.
4. After GitHub publishes it, use **Settings → Pages → Visit site**. Typical URL: `https://YOUR-USERNAME.github.io/terbinafine-poster-references/`. This is only a pattern — use the actual URL GitHub reports.
5. Test with phone, check all eight Read publication links and the Download references PDF button. Create final QR **from the exact live HTTPS URL**. Do not change the repository name or username after printing.

Note: the site is public, and GitHub Pages has no guaranteed perpetual hosting. Keep offline backups of the HTML/PDF.
